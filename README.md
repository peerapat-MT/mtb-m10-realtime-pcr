# การตรวจวินิจฉัยเชื้อ *Mycobacterium tuberculosis* complex (MTB) ด้วยวิธี Real-time PCR

สไลด์อบรมแบบโต้ตอบ 35 แผ่น: โครงสร้างและการก่อโรคของเชื้อ MTB, การเก็บและเตรียมเสมหะ, การตรวจด้วย STANDARD M10 (MTB-RIF/INH, MDR-TB), QC, การแปลผลและรายงาน และการบันทึกผลใน NTIP

**โดย ทนพ.พีรภัทร ภักตะภา**
นักเทคนิคการแพทย์ชำนาญการ
กลุ่มงานเทคนิคการแพทย์และพยาธิวิทยาคลินิก โรงพยาบาลอำนาจเจริญ

## ไฟล์อื่น

`blender_models/` มีโมเดล 3D (.glb) ภาพเรนเดอร์ (.png) และคลิปแอนิเมชัน (.mp4) ไฟล์ .glb แทรกใน PowerPoint ได้ทางเมนู แทรก > โมเดล 3 มิติ

## ข้อควรทราบ

- ภาพ 3D ทั้งหมดเป็นแบบจำลองเพื่อการสอน ไม่ใช่สัดส่วนหรือโครงสร้างภายในจริงของเชื้อหรือ cartridge
- ภาพหน้าจอเครื่อง รายงาน และ NTIP ในสไลด์เป็นภาพจำลอง (DEMO) ไม่มีข้อมูลผู้ป่วยจริง
- ก่อนนำไปใช้ปฏิบัติงาน ให้เทียบกับ IFU ของผลิตภัณฑ์ที่ใช้จริงและ WI ที่หน่วยงานอนุมัติ
